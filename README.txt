LUMA SKIN WEBSITE — QUICK START

Files:
- index.html     Home page
- products.html  Products page (six sample products + category filters)
- about.html     About page
- contact.html   Contact page (demo form)
- style.css      Responsive design
- script.js      Mobile menu, product clicks, filters and demo form validation

IMPORTANT: GA4
The four HTML pages currently contain the placeholder G-XXXXXXXXXX.
After you create your own GA4 web data stream, replace every occurrence of
G-XXXXXXXXXX in ALL FOUR HTML files with your actual Measurement ID.

The contact form is for demonstration only. It does not send or store data.
The product interaction event is select_item. The form event is demo_form_submit.
Do not rename the demo form event to generate_lead: no actual lead is collected.

Images are loaded from Unsplash using public image URLs, so an internet connection
is needed for them to display. This project contains exactly four HTML pages.
